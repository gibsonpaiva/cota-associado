6. FLUXO TÉCNICO DE CAPTAÇÃO E INTEGRAÇÃO DO SITE
--------------------------------------------------------------------------------
1. O visitante seleciona seus dados (Nome, WhatsApp, CPF e Faixa FIPE).
2. O simulador calcula o valor instantaneamente na tela via JavaScript Vanilla.
3. Ao clicar em "Contratar com este Plano" ou "Falar com Consultor":
   a) O lead é salvo no banco de dados em nuvem (Supabase).
   b) É disparado um Webhook para o N8N (Notificação no Telegram e E-mail).
   c) É aberto o WhatsApp oficial (+55 31 3191-5995) com a mensagem pré-formatada.
4. O consultor gerencia os leads pelo Painel Administrativo (/admin.html).
5. Se uma cotação for cancelada, é exigido o registro do motivo no painel,
   o qual fica disponível para consulta direta no bot do Telegram via botão.
